# Frontend Contract Guard — desktop downloads

Installers for the Frontend Contract Guard desktop app. This repository contains no source code:
each [release](https://github.com/MidoHussei1993/Contract-Guard-releases/releases) holds only the
installers and the files the app uses to update itself.

| macOS (Apple Silicon) | [frontend-contract-guard-mac-arm64.dmg](https://github.com/MidoHussei1993/Contract-Guard-releases/releases/latest/download/frontend-contract-guard-mac-arm64.dmg) |
| macOS (Intel) | [frontend-contract-guard-mac-x64.dmg](https://github.com/MidoHussei1993/Contract-Guard-releases/releases/latest/download/frontend-contract-guard-mac-x64.dmg) |
| Linux (AppImage) | [frontend-contract-guard-linux-x86_64.AppImage](https://github.com/MidoHussei1993/Contract-Guard-releases/releases/latest/download/frontend-contract-guard-linux-x86_64.AppImage) |
| Linux (.deb) | [frontend-contract-guard-linux-amd64.deb](https://github.com/MidoHussei1993/Contract-Guard-releases/releases/latest/download/frontend-contract-guard-linux-amd64.deb) |

AppImage).
